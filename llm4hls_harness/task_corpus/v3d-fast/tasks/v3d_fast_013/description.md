# V3-D 公开 kernel 任务

## 功能语义

rows 和 cols 的合法范围均为 [3, 6]；活动矩形内部元素输出自身及上下左右五点之和，活动矩形边界及矩形外的全部输出必须为 0。合法输入元素范围为 [-1000000, 1000000]。

## 接口与约束

- 顶层函数必须保持为 `kernel(const int input[6][6], int output[6][6], int rows, int cols)`。
- 数组容量固定为 6x6；必须定义活动矩形外以及边界位置的输出。
- 只允许修改 `kernel.cpp`；header、公开 testbench 和任务元数据均为只读。
- 公开 testbench 只给出示例，提交实现必须满足上述全部合法输入。
